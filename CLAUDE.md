# Project orientation

Read [AGENTS.md](AGENTS.md) for shared project instructions, then
[README.md](README.md) and [the documentation map](docs/README.md).

The public repository is `AventurineDream/SimulationQuery`. The Python package
and module remain `improv-troupe` and `improv_troupe`.

Private evidence and operating handoffs are owned by the SimulationQuery Drive
folder. Its current index supersedes machine-specific instructions in historical
copies. The old local SimulationQuery directory is deprecated.

Use an isolated workspace, run the offline checks, preserve frozen research
identity and completed evidence, and keep deployment, restart, closure, and
publication decisions separate from repository maintenance.
