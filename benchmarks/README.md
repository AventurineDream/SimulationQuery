# Benchmark and preparation records

This directory preserves dated public summaries and approved/example inputs.
Dates and model selections describe the conditions of each record, not current
server state. Read the corresponding research protocol before comparing results.

- `first-run-*` records the initial cast, opening, model assignment, and preflight.
- `s01-day-2-model-review-2026-08-24.md` records the earlier S01 review.
- `s02-test-*` supplies the historical inputs referenced by the isolated test
  season provisioning script.

The raw `season-1-porch-rehearsal-*` batch JSON and two CSV result tables are
preserved byte-for-byte in the private Drive archive. Their absence from the
public tree does not invalidate the dated summaries or authorize a new run.
See [project organization](../docs/PROJECT_ORGANIZATION.md) for evidence storage.
